## Subline 0.2.3

- **Bios translate again.** A Discord change stopped bios from translating. They work again.
- **Previews show the full ✦ in place.** Press ✦ on a message and the full translation replaces the ≈ line. Long messages come through whole.
- **Better context for replies and Hinglish.** ✦ reads the message being replied to. Hinglish and other mixed languages translate more naturally.
- **Plain messages.** Subline's notices and errors use simpler words.
- **Uninstall is safer.** It asks you to quit Discord first. If anything stops it, nothing is changed and Discord keeps working.
- **Discord always starts.** If Subline breaks for any reason, Discord still opens without it.
- **Windows repairs itself after Discord updates.** Subline waits for Discord's own update to finish, then puts itself back.
- **Server codes work on VPNs.** People on the same VPN can each use a server's code.
- **AI checkout cannot charge you twice.** A second payment for the same plan is refused.
- **New site: subline.page.** Questions go to support@subline.page.
- **A one-time notice in Discord** tells you when your Subline app is too old.

Translations update by themselves. Download and open the new installer from subline.page once to get the repair fixes. New installs: same link.
