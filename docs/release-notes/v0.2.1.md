## Subline 0.2.1

- **The buttons on messages are back.** A Discord update hid the 🌐 and ⚡ buttons that appear when you hover a message. They show again.
- **Bios translate in more places.** The full profile, the profile beside a DM, and the small profile card now show the translated bio.
- **Fewer missing ✦ lines on profiles.** When Google is unsure of a bio or status, ✦ still gets its turn.
- Built on a newer Vencord (1.15.9), and every patch Subline uses is now checked against Discord's live code before each release.

Nothing to do: Subline updates itself. New installs: download the installer for your computer below.
