## Subline 0.2.1

- **The buttons on messages are back.** A Discord update hid the 🌐 and ⚡ buttons that appear when you hover a message. They show again.
- **⚡ on every message for AI subscribers.** Press it to translate a message Subline skipped. A name or a message already in your language says "nothing to translate here".
- **Statuses and bios translate in place.** The profile shows the translation. Click ✦ to see the original. Bios work in every profile layout.
- **Custom emoji stay out of translations.** No more numbers or :names: in the translation line.
- **Fewer missing ✦ lines.** When Google is unsure, ✦ still gets its turn. Long messages, edits and quiet channels are handled more reliably.
- **Back within seconds after a Discord update.** When Discord updates itself, Subline now puts itself back right away instead of within the hour. On Windows it checks every 5 minutes.
- Built on a newer Vencord (1.15.9), and every patch Subline uses is now checked against Discord's live code before each release.

Translations update by themselves. For the faster fix after a Discord update, download and open the new installer for your computer below once. New installs: same link.
