Where your messages go

Translating means sending text somewhere. Here's exactly where.

WhatGoes whereStored?
Message textGoogle for the instant ≈ line. For the ✦ line, Subline's own relay gets the message and a few messages before it. It sends them to OpenRouter, which runs the AI on Groq or a similar host, and returns the translation. If OpenRouter fails, the relay sends them straight to Groq.No. The relay stores no message text.
Who sent itFor the ✦ line, the sender's Discord username goes to the relay with the text, so the AI can tell who said what. If a message mentions a person, channel, or role, that name goes as part of the text, to Google and the relay. Avatars and server names are never sent.No.
Profiles, embeds and morePaid installs only, and only with Translate profiles, embeds and more on. Texts go in small batches, with no messages around them and no names. The ✦ translation comes from Subline's own relay. Text shown as a line under the original also goes to Google for the quick ≈ line. Text shown only when you hover a small ✦ goes to the relay alone. What goes: embed, poll, forwarded message and reply preview text, only from channels that translate messages. So never from a DM or group DM you have not turned on, and never from a channel you switched off. Custom statuses and About me text of people whose profile, member list row or DM list row you see. Channel topics and descriptions, voice channel statuses, thread and forum post titles, forum tags, stage topics, event descriptions, server rules and onboarding questions, only in servers, never in DMs. Text Subline is sure is in your language is not sent. At most 200 of these texts a day. Messages always go first.The relay stores no text. Your device keeps these translations for up to 30 days, at most 2,000 of them, so the same text is not sent twice. It also keeps a count of today's texts.
Your Subline codeAn access token that unlocks the ✦ AI. No name, email, or personal info is attached. It goes to the relay only when you translate.A count of today's translations for the code, deleted after 2 days. A daily marker that the code was used, stored as a 16-hex SHA-256 hash of the code, deleted after 2 days.
Free install idFree installs send a random id when Discord starts and with each free ✦. It times your 7 free days and counts your 3 free ✦ previews a day. It is not tied to your name or account. Each free ✦ also counts your IP address, to limit abuse.A count of today's translations for the id, deleted after 2 days. A daily marker that the id was used, stored as a 16-hex SHA-256 hash of the id, deleted after 2 days. The time the id first got a translation, kept 90 days. The app keeps its own record of when your trial started, and that is what ends it. A count per IP address, deleted after 2 days. For an IPv6 address, only its first half is used.
Usage dataThe Discord app sends none. For each request, the relay records whether it worked, the plan, and how many messages it had. Each record carries a short hash of the code or id, never the code or id itself. No message text, no names.Daily totals for all users together, kept 35 days. The per-request records are kept in Cloudflare's analytics service.
  • off
    DMs are off. A DM is never translated on its own. You can turn one on per conversation. Or press ⚡ on one message to translate it. That sends it and the few messages before it.
  • off
    Your own messages are never translated. If you read English, Subline skips text it is sure is English before sending anything. Everything else goes to Google, which skips what is already in your language. After a free trial ends, only the messages you click go. With ✦ on, a few recent messages, yours included, go to the relay as context.
  • you
    Turn it off. To stop one channel, hover over a message in it and click the globe button, labeled Disable auto-translate here. Click it again to turn the channel back on. To stop every server channel, switch off Global Auto in the VcTranslate plugin settings. After that, only channels you turn on with the globe button translate.
