Where your messages go

Translating means sending text somewhere. Here's exactly where.

WhatGoes whereStored?
Message textGoogle for the instant ≈ line. For the ✦ line, Subline's own relay gets the message and a few messages before it. It sends them to OpenRouter, which runs the AI on Groq or a similar host, and returns the translation. If OpenRouter fails, the relay sends them straight to Groq.No. The relay stores no message text. It keeps counts only.
Who sent itFor the ✦ line, the sender's Discord username goes to the relay with the text, so the AI can tell who said what. If a message mentions a person, channel, or role, that name goes as part of the text, to Google and the relay. Avatars and server names are never sent.No.
Your Subline codeAn access token that unlocks the ✦ AI. No name, email, or personal info is attached. It goes to the relay only when you translate.A usage count, nothing more.
Free install idFree installs send a random id when Discord starts and with each free ✦. It counts your 3 a day. It is not tied to your name or account. Each free ✦ also counts your IP address, to limit abuse.A usage count per id and per IP address. The IP address count is deleted after 2 days.
Usage dataThe Discord app sends none. The relay keeps a count per code or free install id: how many translations, and whether they worked. No message text, no names.Counts only.
  • off
    DMs are off. A DM is never translated on its own. You can turn one on per conversation. Or press ⚡ on one message to translate it. That sends it and the few messages before it.
  • off
    Your own messages are never translated. If you read English, Subline skips text it is sure is English before sending anything. Everything else goes to Google, which skips what is already in your language. With ✦ on, a few recent messages, yours included, go to the relay as context.
  • you
    Turn it off. In the VcTranslate plugin settings, switch off Global Auto (auto-translate every server channel). After that, only channels you turn on with the globe button translate. Turning off one server channel while that switch is on does not work yet.
