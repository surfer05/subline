✦ Subline

Read every Discord message in your language.

Subline adds a translation under messages that aren't in your language. It runs inside the Discord you already have — same app, same account, same servers.

How it works

  1. Download and open Subline.
  2. It finds Discord, asks which language you read, and patches it.
  3. Discord restarts. Translations start appearing under messages.

Subline modifies your existing Discord rather than installing a separate client, so nothing about your account, servers or settings changes. It keeps a copy of the original files and can put them back exactly — see uninstalling.

Two speeds

A fast translation appears almost immediately, then a better one replaces it if you've set up an AI provider. The marker tells you which you're looking at:

≈Fast. Google Translate. Arrives in under a second, free, no setup. Good for getting the gist.
✦Better. An AI model that sees the surrounding conversation, so it handles slang, replies and mixed-language messages far better. Needs a free API key.

The fast one always arrives first, so you're never waiting. The better one quietly replaces it when it lands, and never overwrites a good translation with a worse one.

What gets sent where

Translating text means sending it somewhere. Being plain about that:

  • Messages in channels you've enabled are sent to Google Translate, and to your chosen AI provider if you've added a key.
  • Nothing is sent to us. Subline has no server and no account — your API key stays on your machine.
  • Direct messages are off by default. Auto-translation covers server channels only; you have to switch on each private conversation yourself.
  • The diagnostics log records what failed, never what anyone said.

If a conversation is one you wouldn't want passing through a third-party API, don't enable it. That decision stays yours per channel.

Installing

Your computer will warn you about this app

Subline isn't code-signed yet — certificates cost several hundred dollars a year, and this is a free project. The warning means "we can't confirm who wrote this", not "this is known to be harmful". Here's exactly what you'll see and what to click.

macOS

  1. Open the downloaded .dmg and drag Subline to Applications.
  2. Open it. macOS says "Apple could not verify Subline is free of malware." Click Done.
  3. Go to System Settings → Privacy & Security, scroll down, and click Open Anyway next to the message about Subline.
  4. Subline will also ask for App Management permission — that's what lets it modify Discord. It can't work without it.

Windows

  1. Run the downloaded .exe.
  2. Windows shows a blue "Windows protected your PC" screen. Click More info, then Run anyway.
  3. Follow the installer, then let Subline walk you through the rest.

If Discord is open, Subline will ask to close it first — it can't safely change files that Discord is using.

Keeping it working

Discord updates itself regularly, and every update wipes out modifications like this one. Subline installs a small background task that notices and repairs it, so translation doesn't silently stop working a few weeks after you install it.

Uninstalling

Open Subline and click Uninstall. It restores Discord's original files byte for byte, removes the background task, and asks whether to keep your settings in case you come back. Deleting the Subline app alone won't undo the patch — use the button.
